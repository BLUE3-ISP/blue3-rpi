## Achados de código para decisão

- `rpi_start.sh:212-215`: o fallback de Desktop instala o conjunto mínimo e retorna
  antes do `set-default graphical.target` feito para metapacotes. Verificar o boot
  desse caminho antes de prometer que a escolha Desktop muda o alvo padrão.
- `rpi_start.sh:85-90`: backups usam sempre o mesmo sufixo e podem perder a versão
  anterior em reexecução. Definir retenção/backup por execução e recuperação.
- `rpi_start.sh:130-136` e `159`: falhas de serviço/NTP/módulo são toleradas; o fim
  do script não é uma prova de que o subsistema funciona. Avaliar diagnóstico final.
- `rpi_start.sh:38-44`: aceita Debian e não exige identificação positiva de uma placa
  Raspberry Pi. Decidir se esse alcance é intencional.

Nenhum desses caminhos foi corrigido ou testado em hardware. Não se verificou
qualidade/disponibilidade do espelho, NTP, pacotes, imagem do sistema, barramentos
ou ambiente gráfico. A sintaxe Bash e os links são verificações locais de documentação,
não aceitação de instalação. O número da versão é mantido pela exceção documental
já escrita em `version.md`; não há alteração em código/configuração/build.
